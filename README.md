# ゆるり — おくすりリマインダー

朝・昼・晩のざっくりした時間帯で、服薬を記録するデスクトップ向けブラウザ拡張機能です。分単位の服薬予定を登録する必要はありません。

## できること

- 薬ごとに朝・昼・晩を複数選択。名前、メモ、有効・一時休止を設定できます。
- 服薬記録はポップアップから操作し、薬の追加・編集は日本語IME入力のため通常のタブで開きます。
- 「飲みました」で記録。「記録済み」で取り消せます。
- 現在の時間帯に未記録の薬がある場合のみ、時間帯ごとに1回通知します。
- その時間帯の通知を1時間延期できます。延期後も未記録なら、同じ時間帯のうちに再通知します。
- 今日の進捗、直近7日間の記録を確認できます。記録は90日間保持します。
- 薬と通知の設定を、ブラウザ標準機能でデバイス間同期します。
- Chrome / Edge用とFirefox用に、Manifest V3形式でビルドします。

## インストール

最初にNode.js 20以降で `npm run build` を実行し、`dist/` にインストール用ファイルを生成してください。追加のnpmパッケージ、ランタイムの外部ライブラリ、サーバーは不要です。

### Chrome / Edge

1. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` を開きます。
2. 「デベロッパーモード」または「開発者モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このフォルダーの **`dist/chromium`** を選択します。
4. ツールバーに「ゆるり」を固定して開き、おくすりを追加します。

別のパソコンへ持ち出す場合は `dist/yururi-chromium.zip` を展開し、展開したフォルダーを同じ方法で読み込んでください。公開鍵をmanifestに指定しているため、配置場所が違っても開発版の拡張機能IDが揃います。

Chrome 120以降と、それに対応するChromiumベースのEdgeを対象とします。組織の管理ポリシーで開発版の読み込みが禁止されている場合があります。

### Firefox

1. Firefox 140以降で `about:debugging#/runtime/this-firefox` を開きます。
2. 「一時的なアドオンを読み込む」を選び、**`dist/firefox/manifest.json`** を指定します。
3. ツールバーから「ゆるり」を開きます。

これは開発用の一時読み込みです。**Firefoxを終了すると解除され、データが失われる場合があります。** 日常的に使うには、`dist/yururi-firefox.zip` をMozilla Add-onsに提出して署名済みXPIを取得し、署名済み版をインストールしてください。ストアでの一般公開をせず、署名付きで自己配布することもできます。このリポジトリには未署名版を用意しています。

薬の設定を同期するため、Firefoxのインストール時には健康情報に関するデータ送信の同意が表示されます。送信先はFirefox標準同期です。開発者のサーバーへ送信する処理はありません。

## 通知の考え方

| 時間帯 | 記録上の区分 | 初期設定の通知目安 |
| --- | --- | --- |
| 朝 | 4:00〜11:59 | 10時ごろ |
| 昼 | 12:00〜17:59 | 15時ごろ |
| 晩 | 18:00〜翌3:59 | 21時ごろ |

通知目安を過ぎて、現在の時間帯に未記録の薬があると「飲み忘れていませんか？」と通知します。5分ごとの確認なので、目安の時刻ぴったりに出す仕組みではありません。目安は各時間帯の範囲内で1時間単位で変更できます。晩は翌0〜3時も選択できます。

深夜0〜3時59分は前日の「晩」です。服薬上の日付は4時に切り替わり、端末のローカル時刻を使います。朝・昼・晩の記録ボタンは当日の分をいつでも操作できます。別の日の服薬を誤って変更しないよう、日付が切り替わった画面からの記録は拒否して再表示します。

同じ時間帯は、通知を閉じても繰り返し通知しません。「1時間あとにする」を押したときだけ再通知対象に戻ります。時間帯が終われば、その時間帯の未記録は通知しません。通知をクリックすると記録画面をタブで開きます。通知だけで服薬済みにはしません。

ブラウザの終了中や端末のスリープ中は通知できません。再開時に現在の時間帯を確認し、通知目安を過ぎて未記録ならお知らせします。過ぎた時間帯の通知をまとめて出すことはありません。OSの通知設定、集中モードなどにより表示されない場合は「通知をテスト」で確認してください。

## 同期されるもの・されないもの

**同期するもの：** 薬の名前、メモ、朝昼晩の設定、有効・休止、通知の有効・無効、通知目安、通知への薬名表示。

**この端末だけに保存するもの：** 服薬記録、通知済み状態、通知の延期。別の端末の服薬記録を見て通知を止める機能はありません。記録に使う端末を決め、ほかの端末ではOS側で通知を無効にすると重複表示を避けられます。拡張機能内の通知設定は同期されるので、ここで無効にすると同期先にも反映されます。

各端末で同じブラウザの同一アカウントにログインし、そのブラウザの拡張機能・設定の同期を有効にしてください。**Chrome・Edge・Firefoxはそれぞれ別の同期基盤なので、異なるブラウザ同士では共有されません。** モバイル版や同期ログイン、OS通知の可否はこの実装で自動判定しません。「保存しました」はブラウザの同期領域への保存完了を示し、サーバーや別端末への反映完了を保証する表示ではありません。

同期には同じ拡張機能IDが必要です。Firefoxでは固定のアドオンID、Chrome/Edgeの開発版では固定の公開鍵を使用しています。Chrome Web Store・Edge Add-onsに配布する場合は、各ストアのIDと公開鍵に合わせて `scripts/build.mjs` を調整してください。開発版とストア版でIDが変わる場合は、設定の移行が必要です。

薬は40件までです。薬ごとに別キーで保存して同期の競合を抑えていますが、同じ薬を複数端末で同時に編集した場合はブラウザ側の競合解決によって一方の設定が優先されます。同期容量や書き込み頻度の制限で保存に失敗した場合は、画面にエラーを表示し、保存済みとは表示しません。

## 開発

Node.js 20以降を使用します。追加のnpmパッケージは不要です。

```sh
npm test
npm run build
npm run check
```

- `src/core.js`: ローカル日付、時間帯、未記録と通知の判定、入力検証。
- `src/background.js`: アラーム、通知、保存、メッセージ処理。Chrome/EdgeはService Worker、Firefoxはイベントページです。
- `src/app.html`, `src/app.js`, `src/app.css`: ポップアップ、タブ表示、設定、履歴。
- `scripts/build.mjs`: ブラウザ別manifestと、外部コマンドに依存しないZIPを生成します。
- `tests/`: 深夜・日付境界、通知済み抑制、スヌーズ、再起動、保存失敗、Chrome/Firefox両方のバックグラウンド形式をテストします。

実Chromeでの追加・記録・履歴・編集・削除・設定保存・保存先の検証用に `scripts/browser-smoke.mjs` も用意しています。専用の一時プロファイルのChromeをリモートデバッグ付きで起動して実行してください。既存プロファイルを対象にしないでください。

```sh
# 拡張機能が読み込まれたテスト用Chromeのデバッグポートを指定
CDP_URL=http://127.0.0.1:9228 node scripts/browser-smoke.mjs
```

Chromeの開発用 `Extensions.loadUnpacked` APIを有効にして起動した環境では、`LOAD_EXTENSION=1` を追加して一時読み込みできます。テスト用データは専用プロファイルに保存されます。画面のスクリーンショットは `artifacts/` に出力します。

Firefoxの実ブラウザ確認用には `scripts/firefox-smoke.py` を用意しています。専用プロファイルに `user_pref("marionette.port", 2831);` を設定し、`MOZ_REMOTE_ALLOW_SYSTEM_ACCESS=1 firefox --headless --no-remote --profile <専用プロファイル> --marionette` で起動後、`python3 scripts/firefox-smoke.py` を実行します。Pythonの標準ライブラリのみを使用します。
